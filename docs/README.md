# ReloGo documentation

Use one of these two entry points:

| Reader | Start here | Purpose |
| --- | --- | --- |
| Product owner, developer, or reviewer | [PLAN.md](PLAN.md) | Canonical product status, roadmap, launch checklist, known issues, and definition of done |
| AI agent or automated tool | [ai/AI_HANDOFF.md](ai/AI_HANDOFF.md) | Current architecture, repository rules, verification commands, git state, and next tasks |

Supporting references:

- [DEPLOYMENT.md](DEPLOYMENT.md) — detailed deployment commands and platform setup.
- [ai/PROJECT_MAP.md](ai/PROJECT_MAP.md) — annotated file tree.

`PLAN.md` is the source of truth for current status and remaining work. The
supporting documents should not maintain separate competing roadmaps.
